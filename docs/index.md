# Redes Neurais e Deep Learning · Projeto

Projeto de classificação de sessões de compra on-line, desenvolvido por **Sérgio Carmelo Tôrres Filho** para a eletiva de Redes Neurais e Deep Learning do Insper (2026.2).

O [EDA](projects/eda/index.md) reúne a inspeção do dataset, as análises descritivas e o pipeline de pré-processamento que será reutilizado na etapa de modelagem. Nesta primeira entrega, **nenhum modelo é treinado**.
